Canaan，从一间安静的书房开始

先不造一座庞大的知识城市。从一张真正好写、好读、能持续生长的书桌开始。

#随笔#建站

Canaan 的第一版不是平台，是我的个人博客和实验室。写作与阅读发生在同一份内容上：我在本地创作，读者打开网页，就能看到安静、清晰、可以触摸的文章。

为什么先做小

真正重要的基础只有三个：一份可演进的结构化正文、一个不会打断思路的编辑器、一个愿意让人停留的阅读空间。评论、协作和商业化都可以以后再来。

完整的系统，也可以从少数经过提炼的基础生长出来。

这一版已经能做什么？

像 Markdown 一样输入标题和列表，用 / 或 + 选择内容块，写公式、表格、代码和可交互实验，并把同一份 Tiptap JSON 发布成博客。

这里会持续记录 Canaan 的设计、技术和我真正想弄明白的事。
